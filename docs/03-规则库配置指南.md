# 03 规则库配置指南

DFM 判定的全部标准都来自两类外置文件，**改标准不需要改代码**：

| 文件 | 作用 | 谁改 |
| --- | --- | --- |
| `rules/capability/<板厂>.yaml` | 板厂制程能力库（判定阈值来源） | 工艺/工程 |
| `rules/checks.yaml` | 规则集：检查开关、阈值与严重度覆盖、评分模型、装配与拼板阈值、自定义规则 | 工程/项目 |

---

## 1. 搜索路径与优先级

规则文件按下列顺序查找，**先找到先用**（用户目录覆盖出厂文件）：

```
1. 环境变量 EVAN_DFM_RULES 指向的目录
2. %APPDATA%\EvanDFM\rules\           ← 用户自定义 (推荐)
3. <程序目录>\rules\                   ← 出厂默认 (随包发布)
```

- 能力库文件位于各搜索路径下的 `capability/` 子目录
- 插件目录：`EVAN_DFM_PLUGINS` > `%APPDATA%\EvanDFM\plugins` > `<程序目录>\plugins`
- 界面「规则库 → 板厂能力库」的 **复制为用户副本** 会把出厂 YAML 复制到用户目录
- 改完文件后：界面点 **重新载入**（或 **重新加载**），命令行直接重跑即可；程序内按文件 mtime 自动失效缓存

查看实际生效路径：

```bat
python -m dfm rules path
python -m dfm rules list
```

## 2. 板厂制程能力库

### 2.1 顶层结构

```yaml
meta:
  factory: "示例板厂"                 # 界面显示名
  aliases: ["示例板厂", "板厂A", "myfab"]   # 别名, 命令行/配置里可用中文指定
  revision: "2026-08-28"             # 能力库版本 (报告可追溯)
  source_files: ["硬板-制程能力评估.xlsx"]   # 数据来源, 建议保留以便追溯
  unit_note: "mil->mm 换算 1mil=0.0254mm"

board_types:
  rigid:                             # 板型 id (可自定义, 如 rigid/flex/rigid_flex)
    label: "硬板"
    levels: [standard, automotive, extreme]     # 能力等级列表
    level_labels:
      standard: "常规"
      automotive: "常规(车规)"
      extreme: "极限"
    standard: { ... 能力段 ... }
    automotive: { ... }
    extreme: { ... }
  flex:
    label: "软板及软硬结合板"
    levels: [standard, extreme]
    standard: { ... }
```

要点：

- **文件名 = 板厂 id**（`jlcpcb.yaml` → `jlcpcb`）。新增板厂 = 新建一个 YAML，程序自动发现
- 每个板型下每个等级都是**完整独立的一份能力段**（不继承），便于按等级收紧
- 数值项统一写成 `{value: 数值, unit: mm|um|mil|percent|ratio, note: "说明"}`，读取时自动换算为 mm

### 2.2 能力段（standard 下的键）

| 段 | 关键键 | 被哪些检查使用 |
| --- | --- | --- |
| `panel` | `max_working_panel`（最大工作板）、`max_array`、`min_pcs`、`min_breakaway_rail`（最小工艺边） | 拼板/板尺寸 |
| `trace` | `min_line_spacing_by_copper`（**按成品铜厚分档的线宽/线距**）、`line_width_tolerance`、`hole_to_hole_spacing`（`pth_to_pth` 等，CAF）、`trace_to_board_edge`（`inner`/`outer`）、`smt_pad_position_tol`、`aoi_min_detect` | 最小线宽/线距、孔壁间距、线路到板边 |
| `lamination` | `board_thickness`（`min_mm`/`max_mm`）、`dielectric_thickness_tol`、`layer_registration` | 板厚范围、Info 备注 |
| `drill` | `min_mech_drill`、`max_mech_drill`、`min_laser_via`、`min_laser_blind`、`laser_dielectric_limit`、`annular_ring_mech`、`annular_ring_laser`、`pth_drill_tol`、`npth_drill_tol`、`hole_wall_roughness`、`hole_position_tol`、`npth_to_edge` | 孔径、单边孔环、激光孔、NPTH 到板边 |
| `plating` | `pth_aspect_ratio`（**纵横比上限**）、`blind_via_fill_aspect`、`blind_via_fill_rate`、`blind_via_fill_dimple`、`plating_uniformity` | PTH 纵横比、盲孔填孔 |
| `plug_hole` | `resin_plug_min`（`hole_mm`/`board_thickness_mm`）、`resin_plug_depth`、`ink_plug_depth`、`plug_aspect_ratio`、`soldermask_plug_min`、`resin_plug_cap_copper` | 塞孔条件/深度/纵横比 |
| `solder_mask` | `min_bridge_by_copper`（**按铜厚 oz 分档**）或 `min_bridge_single`、`min_opening`、`ink_thickness_by_copper`、`opening_tolerance` | 阻焊桥、阻焊开窗、油墨厚度 |
| `silkscreen` | `min_line_width`、`min_clearance`、`min_char_size`（`width_mil`/`height_mil`）、`min_to_solder_mask`、`min_to_outline` | 丝印线宽/间隙/字符/到阻焊/离成型线 |
| `surface_finish` | `ENIG` / `OSP` / `hard_gold` / `ENEPIG` …（键即支持的工艺） | 表面处理是否支持 |
| `coverlay`（软板） | `min_window_spacing`、`window_to_pad`、`window_to_trace`、`min_window_rect` | 覆盖膜开窗 |
| `routing`（软板） | 锣型/成型相关 | Info 备注 |
| `stiffener`（软板） | 补强板相关 | Info 备注 |
| `test` | `min_pad_2wire`、`min_pad_4wire` | 电测 PAD 尺寸 |

### 2.3 分档表写法

线宽/线距按成品铜厚分档（`um`）：

```yaml
trace:
  min_line_spacing_by_copper:
    - { copper_max_um: 25,                       line_um: 60,  space_um: 60 }
    - { copper_min_um: 25, copper_max_um: 35,    line_um: 70,  space_um: 70 }
    - { copper_min_um: 35, copper_max_um: 52,    line_um: 100, space_um: 100 }
    - { copper_min_um: 52, copper_max_um: 70,    line_um: 127, space_um: 127 }
```

阻焊桥按铜厚分档（`oz`）：

```yaml
solder_mask:
  min_bridge_by_copper:
    - { copper_oz: 1, value: 3.5, unit: mil }
    - { copper_oz: 2, value: 5,   unit: mil }
  # 或者与铜厚无关的单值能力:
  # min_bridge_single: { value: 0.1, unit: mm }
```

线宽公差按线宽分档（写进报告 Info 页）：

```yaml
trace:
  line_width_tolerance:
    - { width_min_um: 50,  width_max_um: 75,  tol_um: 15 }
    - { width_min_um: 100, width_max_um: 150, tol_pct: 20 }
```

### 2.4 新增一家板厂（完整示例）

`%APPDATA%\EvanDFM\rules\capability\myfab.yaml`：

```yaml
meta:
  factory: "某某电子"
  aliases: ["某某", "myfab"]
  revision: "2026-10"
  source_files: ["某某制程能力评估表.xlsx"]

board_types:
  rigid:
    label: "硬板"
    levels: [standard, extreme]
    level_labels: { standard: "常规", extreme: "极限" }
    standard:
      panel:
        max_working_panel: { value: [540, 620], unit: mm }
        min_breakaway_rail: { value: 4, unit: mm }
      trace:
        min_line_spacing_by_copper:
          - { copper_max_um: 35, line_um: 90, space_um: 90 }
          - { copper_min_um: 35, copper_max_um: 70, line_um: 140, space_um: 140 }
        trace_to_board_edge: { inner: 0.3, outer: 0.25, unit: mm }
      drill:
        min_mech_drill: { value: 0.2, unit: mm }
        max_mech_drill: { value: 6.3, unit: mm }
        annular_ring_mech: { value: 0.13, unit: mm }
        npth_to_edge: { value: 0.5, unit: mm }
      plating:
        pth_aspect_ratio: { value: 10, unit: ratio }
      solder_mask:
        min_bridge_single: { value: 0.1, unit: mm }
        min_opening: { value: 0.1, unit: mm }
      silkscreen:
        min_line_width: { value: 0.15, unit: mm }
        min_clearance: { value: 0.15, unit: mm }
      surface_finish:
        ENIG: { note: "支持" }
        OSP: { note: "支持" }
      test:
        min_pad_2wire: { value: 0.4, unit: mm }
    extreme:
      trace:
        min_line_spacing_by_copper:
          - { copper_max_um: 35, line_um: 60, space_um: 60 }
      drill:
        min_mech_drill: { value: 0.15, unit: mm }
        annular_ring_mech: { value: 0.1, unit: mm }
      plating:
        pth_aspect_ratio: { value: 14, unit: ratio }
```

验证：

```bat
python -m dfm rules list                 # 应出现 myfab / 某某电子
python -m dfm analyze board.json --factory 某某   # 中文别名可直接用
```

缺项处理：**能力库里没有的项会被跳过**（报告中标为「该等级无制程数据，需与板厂评估」），不会误判。因此新板厂可以先填最常判的十几项，逐步补全。

## 3. 规则集 `checks.yaml`

### 3.1 检查开关

```yaml
checks:
  fabdata:      { enabled: true }   # 制造数据完整性
  fabrication:  { enabled: true }   # 几何制造 DFM
  netlist:      { enabled: true }   # 开短路 + 网表一致性
  assembly:     { enabled: true }   # 装配 / SMT DFM
  panelization: { enabled: true }   # 拼板 / 工艺边
  capability:   { enabled: true }   # 制程能力比对
  fabnet:       { enabled: true }   # CAD vs FAB 比对
  netclass:     { enabled: true }   # 网络分类 / 阻抗需求
  data_quality: { enabled: true }   # 数据质量与判定覆盖率提示 (元检查)
  custom_rules: { enabled: true }   # 下方声明式自定义规则
  my_plugin_id: { enabled: false }  # 插件检查同样可停用
```

### 3.2 评分模型

```yaml
scoring:
  base: 100.0          # 满分
  cap_penalty: 100.0   # 扣分上限
  weights: { 危险: 10.0, 高: 5.0, 中: 2.0, 低: 0.5, 关闭: 0.0 }
```

`score = base − min(cap_penalty, Σ(权重 × 该级别问题数))`

只想让「危险」影响评分：把 高/中/低 权重设为 0。想让评分更敏感：调高权重或降低 `cap_penalty`。

### 3.3 「接近极限」告警系数

```yaml
limit_warn_ratio: 0.8
```

统一语义（**全系统唯一实现** `dfm.core.issue.warn_threshold`，几何检查、能力比对、
规则集改判都走它）：

| 规则方向 | 违规 | 接近极限（告警带） | 合格 |
| --- | --- | --- | --- |
| 越大越好（线宽/孔径/孔环，阈值 `L`） | 实测 < `L` | `L` ≤ 实测 < `L / ratio` | 实测 ≥ `L / ratio` |
| 越小越好（间距上限等，阈值 `L`） | 实测 > `L` | `L × ratio` < 实测 ≤ `L` | 实测 ≤ `L × ratio` |

`ratio = 0.8` → 告警带宽度为阈值的 1.25 倍；**ratio 越小带越宽（更多"接近极限"提示）**，
越接近 1 带越窄。单条规则可用 `rules.<规则名>.warn_ratio` 覆盖全局值。

### 3.4 潜在损失估算（默认关闭）

```yaml
cost:
  enabled: false        # 报告「潜在损失(估)」列; 金额无统一出处, 对外报告慎用
  currency: CNY
  by_severity: { 危险: 2000, 高: 800, 中: 300, 低: 50, 关闭: 0 }
```


### 3.5 装配 / 拼板阈值（客户或 SMT 厂标准）

```yaml
assembly:
  min_component_spacing: 0.5     # 器件本体最小间距 mm
  component_to_edge: 2.0         # 器件到成型线 mm
  component_to_edge_severity: 中 # 违规严重度
  pad_to_edge: 0.5               # SMD 焊盘到成型线 mm
  fiducial_min: 2                # 每面基准点数量
  fiducial_diameter: 1.0         # 基准点直径 mm
  fiducial_names: [FID, MARK, FP, BENCHMARK, 基准]   # 位号识别关键字
  test_pad_diameter: 0.8
  test_pad_to_edge: 1.27
  test_coverage_min: 0.0         # 网络测试点覆盖率下限 (0=不检查, 0.7=70%)
  chip_pad_symmetry_ratio: 0.8   # 两端焊盘面积对称比 (墓碑效应)
  bga_pitch_min: 0.4             # 细间距器件引脚间距下限
  bga_pad_annular: 0.05          # 细间距器件单边孔环下限
  via_in_pad_allowed: false      # true 时 Via in Pad 只提示
  polarity_required: true

panelization:
  process_edge: 3.0
  mark_count: 3
  mark_to_edge: 3.5
  tooling_hole_count: 2
  min_utilization: 0.7
```

`fiducial_names` 可按客户位号习惯扩展（例如客户用 `MK1`、`BENCHMARK1`）。

### 3.6 按规则名覆盖（比板厂能力更严的客户标准）

```yaml
rules:
  最小线宽:
    enabled: true
    severity: 危险        # 违规时的严重度
    min: 0.1              # 覆盖能力库阈值: 实测 < 0.1 判违规
    warn_ratio: 1.1       # 0.10~0.11mm 判「接近极限」(降一级)
    suggestion: 客户强制最小线宽 0.10mm，请加宽线路或改板厂
  最大机械钻孔:
    max: 3.2              # 实测 > 3.2 判违规 (越大越差的项用 max)
  器件间距:
    min: 0.8
    severity: 高
  最小阻焊桥:
    enabled: false        # 该客户不考核此项 → 完全不报告
```

字段语义：

| 字段 | 作用 |
| --- | --- |
| `enabled: false` | 该规则完全不报告（白名单式豁免） |
| `severity` | 违规时的严重度（`危险/高/中/低/关闭`） |
| `min` / `max` | 阈值覆盖。**配置后按新阈值重判**：合规的问题会被剔除，违规的按 `severity` 报出 |
| `warn_ratio` | 本规则的「接近极限」系数（覆盖全局 `limit_warn_ratio`） |
| `suggestion` / `message` | 覆盖专家建议 / 问题描述 |

`规则名` 必须与问题清单「规则」列完全一致。界面 **规则库 → 规则集 → 从当前结果导入规则名** 可一键导入，避免手打出错。

### 3.7 声明式自定义规则

无需写代码即可新增判定，对**设计参数**做比较：

```yaml
custom_rules:
  - id: CUS-01
    name: 板厚必须为 1.6mm
    category: 板厚
    param: board_thickness
    op: eq
    value: 1.6
    severity: 高
    unit: mm
    message: 板厚 {value}mm 不符合客户标准 {target}mm
    suggestion: 修改叠层板厚为 1.6mm

  - id: CUS-02
    name: 表面处理限定
    category: 表面处理
    param: surface_finish
    op: in
    value: [ENIG, ENEPIG]
    severity: 高
    message: 表面处理 {value} 不在客户允许清单内

  - id: CUS-03
    name: 必须声明阻抗控制
    category: 线路
    param: impedance
    op: true
    severity: 中

  - id: CUS-04
    name: 层数区间
    category: 压合
    param: layer_count
    op: between
    value: [2, 16]
    severity: 中
```

**运算符**（`op` 描述"要求满足的条件"，不满足即报问题）：

| op | 含义 | value 形式 |
| --- | --- | --- |
| `ge` `le` `gt` `lt` `eq` `ne` | 数值比较 | 数值 |
| `between` / `outside` | 在区间内 / 外 | `[lo, hi]` |
| `in` / `not_in` | 属于 / 不属于列表 | `[a, b, ...]` |
| `missing` | 参数缺失即报问题 | 省略 |
| `true` / `false` | 布尔要求 | 省略 |

**可用参数名**（自动量测 + 人工填写合并后的键）：

```
board_size board_thickness layer_count
min_line_width min_spacing inner_line_width inner_spacing
min_mech_drill max_mech_drill min_laser_via min_annular_ring min_annular_ring_laser
pth_to_pth_spacing copper_to_edge_inner copper_to_edge_outer npth_to_edge
solder_mask_bridge solder_mask_opening solder_mask_ink_um
silkscreen_width silkscreen_clearance silkscreen_to_mask silkscreen_to_outline
plug_hole_diameter resin_plug_depth_percent ink_plug_depth_percent
coverlay_spacing coverlay_to_pad coverlay_to_trace
test_pad_2wire test_pad_4wire test_pad_diameter test_pad_to_edge
surface_finish impedance has_microvia has_blind_via has_buried_via
comp_count smd_count tht_count pin_count via_count pth_count npth_count
min_component_spacing component_to_edge fiducial_count_top fiducial_count_bottom
chip_pad_symmetry_ratio bga_pitch bga_pad_annular polarity_marked
panelized process_edge_mm mark_count mark_to_edge_mm tooling_hole_count panel_utilization
```

> 实际可用项取决于数据源：`python -m dfm info <路径>` 或界面「解析并预览」会列出当前板量测到的参数。
> 自定义规则的问题代码（`id`）不会被统一重编覆盖，方便与客户编号体系对齐。

需要**几何级**判定（例如铜箔平衡度、阻抗条长度、孔到槽距离）时，写插件更合适，见 [04 二次开发指南](04-二次开发指南.md)。

## 5. 常见配置场景速查

| 需求 | 做法 |
| --- | --- |
| 换板厂判定 | 新建 `rules/capability/<id>.yaml`，界面选板厂即可 |
| 客户比板厂更严 | `rules.<规则名>.min/max` 覆盖阈值 |
| 某项不考核 | `rules.<规则名>.enabled: false` 或 `checks.<id>.enabled: false` |
| 只想看致命问题 | `scoring.weights` 把 高/中/低 设 0，或界面按严重度过滤 |
| 客户特殊要求 | `custom_rules` 声明式规则 |
| 车规加严 | 能力库新增 `automotive` 等级，界面选该等级 |
| 软板 | 能力库加 `flex` 板型（含 `coverlay`/`routing`/`stiffener` 段），界面板型选软板 |
| 基准点位号命名特殊 | `assembly.fiducial_names` 增加关键字 |
| 允许 Via in Pad | `assembly.via_in_pad_allowed: true` |
| 强制测试点覆盖率 | `assembly.test_coverage_min: 0.7` |

## 6. 能力库来源追溯

能力库的原始依据（板厂评估表、报价单、公开能力页）建议**不要提交到版本库**，
只在 YAML 的 `meta.source_files` 与 `meta.revision` 中记录来源文件名与版本日期即可追溯：

```yaml
meta:
  factory: "示例板厂"
  revision: "2026-10"
  source_files: ["硬板-制程能力评估表-2026-10.xlsx"]   # 只记文件名, 不放原件
```

随包提供的 `rules/capability/jlcpcb.yaml` 取自 JLCPCB 公开能力表，可直接作为模板：
复制一份 → 改名 → 按你板厂的评估表填数值 → 放进用户规则目录即可。
另有 `docs/capability-template.yaml` 为最小可用骨架。
