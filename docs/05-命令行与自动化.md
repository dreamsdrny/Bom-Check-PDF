# 05 命令行与自动化

所有能力都可脱离界面调用，适合批处理、CI 门禁与 MES 集成。

```bat
python -m dfm <命令> [参数]
python evan_dfm.py cli <命令> [参数]     :: 等价写法
evan-dfm <命令>                          :: pip install -e . 之后
```

---

## 命令一览

| 命令 | 作用 |
| --- | --- |
| `gui` | 启动桌面界面 |
| `analyze` | 执行 DFM 分析并导出报告（主命令） |
| `info` | 只解析数据源，打印统计与自动量测参数 |
| `rules` | 规则库管理：`list` / `show` / `template` / `path` / `capability` |
| `checks` | 列出全部检查项（含插件） |
| `skill-export` | 写出 Allegro SKILL 数据导出脚本 |
| `version` | 版本、路径、依赖、能力库与检查数量 |

`python -m dfm`（无参数）：有图形环境时启动界面，否则打印帮助。
任意命令加 `-h` 看完整参数，例如 `python -m dfm analyze -h`。

---

## analyze

```bat
python -m dfm analyze <数据源> [选项]
```

### 数据源

| 参数 | 说明 |
| --- | --- |
| `<source>`（位置参数） | `.brd` / `.json` / Gerber 文件或目录 / ODB++ 目录；类型自动识别 |
| `--type` | 强制指定 `brd\|json\|gerber\|odb\|params\|none` |
| `--fab PATH` | 附加制造数据（主源为 BRD/JSON 时用于 CAD vs FAB 比对） |
| `--cad-nets JSON` | CAD 网表：`{"NET":["R1.1",...]}` |
| `--params JSON` | 设计参数（不填则自动从几何量测） |
| `--extracta EXE` | `extracta.exe` 路径（`.brd` 直读时；留空自动查找） |

### 判定标准

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--factory` | `jlcpcb` | 板厂 id / 中文名 / 别名（如 `嘉立创`、`JLC`） |
| `--board-type` | `rigid` | `rigid` / `flex`（或能力库自定义板型） |
| `--level` | `standard` | 能力等级（`standard`/`automotive`/`extreme` 或自定义） |
| `--copper-um` | `35` | 成品铜厚 um（线宽线距分档） |
| `--copper-oz` | 自动 | 成品铜厚 oz（阻焊桥分档） |
| `--thickness` | 无 | 板厚 mm（**Gerber/ODB++ 必填**才能判纵横比） |
| `--rules YAML` | 搜索路径 | 指定规则集文件 |
| `--modules LIST` | 全部 | 逗号分隔检查 id，如 `fabrication,assembly` |
| `--no-plugins` | — | 不加载插件 |

### 输出

| 参数 | 说明 |
| --- | --- |
| `-o, --out` | 输出文件或目录（文件扩展名决定格式；目录则用板名做文件名） |
| `--format` | `excel,html,text,json,svg`（默认 `excel,text`） |
| `--no-images` | Excel 不内嵌版图截图（更快） |
| `--limit N` | 控制台最多打印 N 条问题（0=全部） |
| `--brief` | 不打印描述与建议 |
| `--json` | 完整结果以 JSON 输出到 stdout（不再打印表格） |
| `--quiet` | 不打印进度 |
| `--strict` | 存在「危险」问题时返回码 1（CI 门禁用） |
| `--view` | 分析后打开版图交叉定位窗口 |
| `--customer` / `--submitter` | 写入报告封面 |

### 精度与规模控制（Python API）

命令行未暴露、但 `analyze(cfg)` 支持的两个上限，用于在**完整性**与**耗时/内存**之间取舍：

| cfg 键 | 默认 | 作用 |
| --- | --- | --- |
| `element_cap` | 400000 | 参与判定的铜箔元素上限；超出则截断并在数据质量中记「截断」 |
| `instance_cap` | 500 | 每规则**留存坐标**的上限；**处数始终全量计数**，超限时报告标 `truncated` |

```python
from dfm import analyze_file
res = analyze_file("D:/board.json", board_thickness=1.6,
                   element_cap=1_200_000, instance_cap=5000)
print(res["data_quality"]["截断"], res["coverage_ratio"])
```

### 输出中的可信度信息

`analyze` 结果（与 `--json` 输出）除问题清单外，还包含：

| 字段 | 含义 |
| --- | --- |
| `coverage` | 每个检查的 `judged_count` / `missed_count` / `ratio` 与未判定规则明细 |
| `coverage_ratio` | 总体判定覆盖率（[REDACTED-UNKNOWN]） |
| `missed_rules` | 未判定规则清单（能力库缺项/数据不足） |
| `data_quality` | 数据源、几何统计、负片合成统计、解析提示、截断、致命问题 |
| `geometry_summary` | 铜箔元素/走线/焊盘/过孔/铺铜/孔/层数、是否截断 |

控制台也会打印一行摘要：

```
判定覆盖率: 88%   未判定规则: 3 项   解析提示: 1 条
```

**CI 门禁建议**：除 `--strict`（危险问题）外，可同时校验覆盖率，避免"因为没判所以通过"：

```bat
python -m dfm analyze board.json --json --quiet > r.json
python -c "import json;r=json.load(open('r.json',encoding='utf-8'));^
import sys;sys.exit(0 if r['coverage_ratio']>=0.8 and r['passed'] else 1)"
```

### 返回码

| 码 | 含义 |
| --- | --- |
| 0 | 成功（或 `--strict` 下无危险问题） |
| 1 | `--strict` 且存在危险问题 / 运行异常 |
| 2 | 参数错误（缺数据源、未知格式） |
| 130 | 用户中断 |

### 示例

```bat
:: 基本用法
python -m dfm analyze board.json -o out --format excel,html

:: Gerber 目录 + 板厂中文别名 + 车规等级
python -m dfm analyze D:\gerber --factory jlcpcb --level extreme --thickness 1.6 ^
                      --copper-um 35 -o D:\out --format excel,html,json

:: Allegro .brd 直读 (指定 extracta)
python -m dfm analyze D:\board.brd --extracta "C:\Cadence\SPB_17.2\tools\bin\extracta.exe" -o out

:: BRD + 制造数据 + CAD 网表 三方比对
python -m dfm analyze D:\brd_export.json --fab D:\gerber --cad-nets D:\cad.json -o out

:: 只做参数化制程能力比对
python -m dfm analyze D:\params.json --type params --modules capability,panelization -o out

:: 只跑装配检查
python -m dfm analyze board.json --modules assembly --format html -o out

:: CI 门禁
python -m dfm analyze board.json --quiet --strict --format json -o out
if errorlevel 1 echo DFM FAIL

:: MES 取结构化结果
python -m dfm analyze board.json --json --quiet > result.json

:: 用自定义规则集
python -m dfm analyze board.json --rules D:\rules\customer_a.yaml -o out

:: 分析后直接看图
python -m dfm analyze board.json --view
```

## info

只解析不判定，用于确认数据可用性、查看自动量测到的参数名（写自定义规则时很有用）。

```bat
python -m dfm info D:\board.brd --extracta C:\Cadence\...\extracta.exe
python -m dfm info D:\gerber --thickness 1.6
python -m dfm info D:\brd_export.json
```

输出：板信息、制造工艺统计、装配统计、制造数据统计、Gerber 层识别（铜层/阻焊/丝印/外形/钻孔数/网络来源）、全部量测参数。

## rules

```bat
python -m dfm rules list                 :: 板厂能力库(含板型/等级/路径) + 检查开关 + 覆盖统计
python -m dfm rules path                 :: 规则库/插件搜索路径与用户规则集位置
python -m dfm rules show                 :: 打印当前生效的完整规则集 (YAML)
python -m dfm rules show --file my.yaml  :: 查看指定规则集
python -m dfm rules template --out my.yaml   :: 导出带注释的规则集模板
python -m dfm rules capability --factory 嘉立创        :: 打印该板厂能力库路径
python -m dfm rules capability --factory 嘉立创 --open :: 并打开
```

## skill-export

无 Cadence extracta 环境时的数据导出方案：

```bat
python -m dfm skill-export                       :: 写到当前目录
python -m dfm skill-export D:\out\evan_dfm_export.il
```

在 Allegro PCB Editor 中：

```
skill load "evan_dfm_export.il"
brdExportJSON                          ; 导出到 .brd 同目录
(brdExportJSON "D:/out/brd_export.json")   ; 或指定路径
```

导出的 JSON 可直接作为 `analyze` 的数据源。

## 批处理示例

### 批量分析一个目录下所有 Gerber 工程

```bat
@echo off
setlocal enabledelayedexpansion
for /d %%D in (D:\jobs\*) do (
  echo ==== %%~nxD ====
  python -m dfm analyze "%%D" --factory 嘉立创 --thickness 1.6 --quiet ^
         -o "D:\reports\%%~nxD" --format excel,html
)
```

### 按客户使用不同规则集

```bat
python -m dfm analyze %1 --rules D:\rules\customer_a.yaml --customer "客户A" -o out
```

### CI（GitLab/GitHub Actions 风格）

```yaml
dfm_gate:
  script:
    - pip install -r requirements.txt
    - python -m dfm analyze board.json --quiet --strict --format json,html -o dfm_out
  artifacts:
    paths: [dfm_out]
```

失败时把 `dfm_out/*.html` 作为产物供评审。

### 环境变量

| 变量 | 作用 |
| --- | --- |
| `EVAN_DFM_RULES` | 规则库根目录（其下 `capability/` 放能力库，`checks.yaml` 放规则集） |
| `EVAN_DFM_PLUGINS` | 额外插件目录 |
| `DFM_DEBUG` | 设为 `1` 时打印完整异常堆栈 |

## Python 内调用

                   progress=print)
