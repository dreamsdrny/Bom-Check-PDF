# 02 用户手册

界面共 8 页，左侧导航按 **工作台 / 分析 / 规则 / 输出 / 系统** 分组。
所有页面共享同一份状态（当前配置、规则集、分析结果），改一处全局生效。

---

## 0. 主窗口

```
┌────────────┬──────────────────────────────────────────────────────────────┐
│  Evan DFM  │  页面标题 / 说明        [数据源芯片][板厂][等级][状态][执行分析] │
│            ├──────────────────────────────────────────────────────────────┤
│  工作台     │                                                              │
│   概览      │                                                              │
│  分析       │                       页面内容                                │
│   数据源    │                                                              │

│  规则       │                                                              │
│   规则库    │                                                              │
│  输出       │                                                              │
│   报告导出   │                                                              │
│  系统       │                                                              │
│   设置      │                                                              │
│  切换主题    ├──────────────────────────────────────────────────────────────┤
└────────────┴ 状态栏: 当前动作 / 坐标 / 版本 ─────────────────────────────────┘
```

**顶栏**是全局快捷区：

- 数据源芯片：显示当前主数据源文件名（未选时提示「未选择数据源」）
- 板厂 / 等级下拉：随时切换判定标准，切换后重跑分析即可
- 状态徽标：空闲 / 分析中 / 完成 / 失败
- **执行分析**（`F5`）：任意页面都能一键运行

**快捷键**

| 键 | 动作 |
| --- | --- |
| `F5` | 执行分析 |
| `Ctrl+E` | 跳到报告导出页 |

## 1. 概览页

- **当前分析结果**：评分仪表（动画）、分级统计卡（总计/危险/高/中/低/定位点/已执行检查数）、结论、预估良率、扣分
- **重点问题（前 8 项）**：按严重度排序，点「定位」直接跳版图
- **标准作业流程**：五步引导，点击直达对应页
- **最近工程**：最近 8 次的板名、数据源类型、板厂、评分、问题数（记录在用户设置里）

没有分析结果时，这里显示快速开始提示。

## 2. 数据源页

### ① 数据源

| 字段 | 说明 |
| --- | --- |
| 数据源类型 | 自动识别 / `brd` / `json` / `gerber` / `odb` / `params` / `none` |
| 主数据源 | `.brd`、导出 JSON、Gerber 文件或目录、ODB++ 目录（「目录...」按钮选目录） |
| 制造数据 | 可选。主源是 BRD/JSON 时，用它做 **CAD vs FAB 网络比对**；主源是 Gerber/ODB++ 时可留空 |
| CAD 网表 | 可选。JSON：`{"NET": ["R1.1","C2.2"]}` 或 `[{"net":"NET","nodes":[...]}]` |
| 设计参数 | 可选。人工填写的制程参数 JSON；不填则**自动从几何量测**。可用「生成模板」得到含全部可填项的模板 |

参数优先级：**人工填写 > 自动量测**。例如自动量测线宽 0.05mm，但你在参数 JSON 里写 `min_line_width: 0.1`，则按 0.1 判定。

**解析并预览**：只解析不判定，用于确认数据是否可用。日志给出：

- 数据源类型、板名、版本
- 制造工艺统计（板尺寸/板厚/铜层数/网络数/节点数/过孔/焊盘/走线/铺铜/测试点/DRC 数）
- Gerber 层识别结果（铜层、阻焊、丝印、外形、钻孔数、网络来源是 X2 还是几何派生）
- **量测到的设计参数**（这些键名可直接用于自定义规则）

### ② 板厂与工艺条件

| 字段 | 说明 |
| --- | --- |
| 板厂 | 来自 `rules/capability/*.yaml` 自动发现，显示名取 YAML 的 `meta.factory`（可用别名匹配，如「嘉立创」「JLC」） |
| 板型 | `rigid` 硬板 / `flex` 软板及软硬结合板（能力库中定义） |
| 能力等级 | 由板厂+板型决定（常规 / 常规(车规) / 极限 …），下拉内容动态来自能力库 |
| 成品铜厚 | `um` 用于线宽线距分档；`oz` 用于阻焊桥分档（留空自动按 35um=1oz 换算） |
| 板厚 | Gerber/ODB++ 无板厚，填写后才能判 PTH 纵横比与塞孔纵横比 |
| 客户 / 提交人 | 写入报告封面 |

### ③ 环境

- `extracta.exe` 路径：留空自动在 `PATH` 与常见 Cadence 安装目录中查找；「自动探测」按钮可手动触发
- **导出 SKILL 脚本**：无 extracta 时的替代路径（在 Allegro 内运行导出 JSON）

## 3. 检查与执行页

上半部分是检查项清单（含插件检查），每行显示：勾选框、中文名、检查 id、分组、说明、**需要的数据**。
按钮：全选 / 全不选 / 仅制造 DFM / 刷新插件。

下半部分：

- **执行分析**：后台线程运行，界面不卡；进度条 + 实时日志（错误红、警告黄、成功绿）
- **执行日志**：每个检查的开始与产出条数、跳过原因、最终汇总
- 完成后显示：问题总数与分级、评分、风险等级、结论、已执行检查

**跳过规则**：检查声明了依赖数据（`design` 几何模型 / `fab` 制造数据 / `params` 参数 / `cad` 网表 / `capability` 能力库），数据不满足就跳过并在日志写明原因。例如只给参数 JSON 时，`fabrication`、`netlist`、`assembly` 都会跳过。

## 4. 问题清单页

- **统计卡**：总计 / 危险 / 高 / 中 / 低 / 定位点 / 已执行检查
- **评分卡**：仪表 + 结论 + 规则集 + 预估良率 + 扣分
- **过滤条**：严重度彩色开关（带数量）、检查项下拉、关键字搜索（匹配代码/规则/类别/描述/网络/层/建议）、右侧显示「显示 N / 总数」
- **表格列**：严重度、代码、检查、类别、规则、数量、实测、要求、单位、层、网络、X、Y、问题描述、专家建议
  - 严重度按级别着色；实测/要求/坐标用等宽字体；悬停显示完整信息与定位点数量
- **明细面板**：选中行的完整信息 + 全部定位点列表（双击跳版图）+ 上一处/下一处 + 在版图中定位

与版图页联动：在任一页选中问题，另一页同步高亮。

## 5. 版图定位页

- **图层面板**：每层一个色块 + 开关；「全显 / 全隐 / 仅铜层」
- **问题定位列表**：仅列出有坐标的问题，按严重度着色；单击定位、双击放大
- **工具栏**：放大 / 缩小 / 适应窗口 / 上一处 / 下一处 / 缩放比例 / 光标坐标（mm）
- **视图操作**：滚轮以光标为中心缩放、左键拖动平移、双击适应窗口、点击彩色标记选中问题

渲染性能：同层同线宽的图元合并为一条绘制路径，十万级图元的板也能流畅缩放。

无几何数据（仅参数化检查）时，此页提示无版图。

## 6. 规则库页

四个标签页，详见 [03 规则库配置指南](03-规则库配置指南.md)。

### 板厂能力库

列出所有已发现的板厂：id、显示名、板型、能力等级、YAML 路径、来源（出厂/用户）。

- **打开文件**：用默认编辑器打开 YAML
- **打开能力库目录**
- **复制为用户副本**：把出厂能力库复制到 `%APPDATA%\EvanDFM\rules\capability\`，用户副本优先级更高（升级软件不丢失自定义）
- **重新加载**：改完 YAML 后点它即可生效（无需重启）

### 规则集（阈值/严重度）

- 当前规则集路径
- **检查开关**：逐项启用/停用
- **规则阈值与严重度覆盖**表格：规则名、启用、严重度、阈值 min、阈值 max、建议文案
  - 「从当前结果导入规则名」：先跑一次分析，再一键把结果里出现过的规则名导入表格，改数值即可
  - **保存到用户规则集**：写入 `%APPDATA%\EvanDFM\rules\checks.yaml`
  - **导出模板**：生成带完整注释的模板

### 自定义规则

表格化编辑声明式规则：启用、代码、规则名、类别、参数、运算符、目标值、严重度、描述/建议（用 `||` 分隔描述与建议）。
「示例: 板厚必须 1.6mm」可一键插入一条完整示例。

### 插件与检查项

- 插件搜索目录列表
- 全部检查项表（id / 名称 / 分组 / 依赖 / 顺序 / 来源=内置或插件文件名）
- **重新加载插件**、**打开插件目录**、**生成插件示例**
- 底部日志显示每个插件的加载状态与注册了哪些检查（失败会给出原因）

## 7. 报告导出页

- **待导出内容**：板名、版本、规则集、问题统计、评分、是否有几何数据
- **格式**（可多选）：

| 格式 | 内容 |
| --- | --- |
| Excel `.xlsx` | Main 封面（单板信息/问题汇总/严重度图例/风险/整板概览图/层映射/EDA 工具/板与装配统计）、Issue summary 问题清单（冻结窗格+自动筛选+分级配色+潜在损失）、Info（制造与装配统计+能力备注）、开短路网表、Issue1..N 单项明细（含定位放大图与全部定位点） |
| HTML `.html` | 单文件交互报告：评分仪表、分级环形图、可过滤问题表、内嵌 SVG 版图（滚轮缩放+拖动+标记点击联动）、能力逐项比对、网络分类、叠层、检查执行情况、规则集与插件来源 |
| JSON `.json` | 结构化结果（去掉体积大的渲染几何），供 MES/二次开发 |
| TXT `.txt` | 纯文本摘要，便于贴邮件 |
| SVG `.svg` | 整板矢量图 + 问题标记 |

- **选项**：Excel 是否内嵌版图截图（无 Pillow 或无几何数据时自动跳过）
- **输出位置**：目录 + 文件名（留空用板名）；客户 / 提交人会写入封面
- 「打开输出目录」「生成规则集模板」

## 8. 设置页

- **外观**：深色 / 浅色主题（立即生效并记忆）
- **输出**：默认报告目录（留空用 `%APPDATA%\EvanDFM\reports`）
- **运行环境**：extracta 路径与自动探测、是否加载插件、规则库与插件搜索目录
- **数据与日志**：日志文件路径、用户设置路径、打开用户数据目录、清空最近工程
- **关于**：版本、Python、程序/资源/用户目录、依赖状态、命令行帮助

用户数据目录 `%APPDATA%\EvanDFM\`：

```
settings.json     界面设置 + 上次配置 + 最近工程
rules\            用户规则集与能力库副本 (优先级高于出厂)
plugins\          用户插件
reports\          默认报告输出
logs\evan_dfm.log 运行日志
```

## 9. 典型工作流

### A. 投板前自查（设计端）

1. 数据源选 `.brd`（或 SKILL 导出 JSON），填板厚、铜厚
2. 板厂选实际下单厂，等级选对应能力（常规/车规/极限）
3. 全部检查执行 → 问题清单按「危险」过滤 → 逐条改
4. 重跑直到无危险项，导出 Excel 存档

### B. 板厂 EQ / 客户资料核对（制造端）

1. 数据源选客户 Gerber 目录，附 CAD 网表 JSON
2. 勾 `fabdata` + `fabnet` + `fabrication` + `assembly`
3. 关注：制造数据完整性（缺层/单位/孤立孔）、CAD vs FAB 开短路、超出本厂能力的项
4. 导出 HTML 发客户（单文件，含版图与定位）

### C. 按客户标准加严

1. 规则库 → 规则集 → 「从当前结果导入规则名」
2. 给 `最小线宽` 设 `min: 0.1`、`severity: 危险`（比板厂能力更严）
3. 保存到用户规则集 → 重跑分析
4. 客户特殊要求（板厚/表面处理/阻抗声明）用「自定义规则」添加
