# 01 快速上手

目标：10 分钟内完成第一次 DFM 分析并导出报告。

---

## 1. 安装

### 方式 A：源码运行（推荐开发/调试）

需要 Python 3.9 以上（建议 3.11/3.12，64 位）。

```bat
cd <project>
pip install -r requirements.txt
python evan_dfm.py
```

依赖说明：

| 包 | 用途 | 缺失后果 |
| --- | --- | --- |
| PySide6 | 桌面界面 | 无法启动 GUI（CLI 仍可用） |
| openpyxl | Excel 报告 | 无法导出 .xlsx |
| PyYAML | 能力库/规则集 | 无法运行（必需） |
| Pillow | 报告内嵌版图截图 | Excel 报告无图，其余正常 |

### 方式 B：打包成 exe

```bat
pip install pyinstaller
build.bat
dist\EvanDFM.exe
```

打包为单文件 exe，双击即用；`rules/`、`assets/`、`plugins/` 会一并打入。

## 2. 准备数据（四种任选其一）

| 你有什么 | 选哪种数据源 | 备注 |
| --- | --- | --- |
| Allegro `.brd` | `brd` | 需本机装有 Cadence（用 `extracta.exe` 无界面提取），首次约 1–2 分钟 |
| SKILL/extracta 导出的 `.json` | `json` | 无 Cadence 环境时最稳妥；导出脚本见下文 |
| Gerber + NC 钻孔（目录） | `gerber` | 建议导出带 X2 属性（`%TO.N`/`%TO.P`），否则网络由几何派生，无法判开短路 |
| ODB++ 工程目录（含 `matrix/matrix`） | `odb` | 信息最完整（层类型、网表、孔径） |
| 只有设计参数 | `params` | 填 JSON 做制程能力比对，无版图定位 |

没有 Cadence 时导出 JSON 的方法：

1. 界面「设置」页 → **导出 SKILL 脚本**（或命令 `python -m dfm skill-export`）
2. 在 Allegro PCB Editor 的 Command 窗口执行：
   ```
   skill load "evan_dfm_export.il"
   brdExportJSON
   ```
3. 得到 `.brd` 同目录下的 JSON，把它作为「主数据源」。

先用自带样例熟悉流程：`samples\brd_export_sample.json`（一块故意留有问题的 2 层板）。

## 3. 图形界面：五步完成分析

### ① 数据源

左侧导航 **数据源**：

- **主数据源**：选文件（`.brd`/`.json`）或点「目录...」选 Gerber/ODB++ 目录，类型会自动识别
- **板厂 / 板型 / 能力等级**：判定标准的来源（板厂A、板厂B、嘉立创；硬板/软板；常规/车规/极限）
- **成品铜厚**：`um` 必填，`oz` 留空自动换算（线宽线距与阻焊桥能力按铜厚分档）
- **板厚**：Gerber/ODB++ 里没有板厚，**必须填**才能判 PTH 纵横比
- 点 **解析并预览**：确认层数、网络数、器件数与「量测到的设计参数」是否符合预期

> 预览里列出的参数名（如 `min_line_width`、`min_mech_drill`）就是后面写自定义规则时用的键名。

### ② 检查与执行

左侧导航 **检查与执行**：

- 勾选需要的检查项（默认全选；数据不满足的检查会自动跳过并在日志说明原因）
- 点 **执行分析**（快捷键 `F5`），下方日志实时滚动
- 完成后顶部显示问题数与评分

### ③ 问题清单

左侧导航 **问题清单**：

- 顶部彩色标签按严重度过滤（危险/高/中/低），可按检查项过滤、可搜索规则/描述/网络
- 单击一行看明细（实测值、要求值、层、网络、定位点数量、专家建议）
- 双击一行 → 直接跳到版图并放大定位

### ④ 版图定位

左侧导航 **版图定位**：

- 左侧图层列表可单独显隐（「仅铜层」一键过滤阻焊/丝印）
- 滚轮缩放、左键拖动平移、双击适应窗口
- 点击版图上的彩色圆点 ↔ 左下问题列表双向联动
- 底部实时显示光标处 PCB 坐标（mm）

### ⑤ 报告导出

左侧导航 **报告导出**：

- 勾选格式（Excel / HTML / JSON / TXT / SVG），选输出目录
- 点 **导出报告**（快捷键 `Ctrl+E` 直接跳到本页）
- Excel：Valor 式多页工作簿，封面含整板概览图，每条问题一页含放大定位图
- HTML：单文件，可直接发客户，支持在浏览器里缩放版图、过滤问题、点标记联动

## 4. 命令行：同样五步

```bat
:: 分析 + 导出
python -m dfm analyze samples\brd_export_sample.json -o out --format excel,html

:: Gerber 目录 (板厚必填才能判纵横比)
python -m dfm analyze D:\gerber --factory 板厂B --board-type rigid --level standard ^
                      --copper-um 35 --thickness 1.6 -o D:\out --format excel,html,json

:: Allegro .brd 直读
python -m dfm analyze D:\board.brd --extracta "C:\Cadence\SPB_17.2\tools\bin\extracta.exe" -o out

:: 附加制造数据做 CAD vs FAB 比对
python -m dfm analyze D:\brd_export.json --fab D:\gerber --cad-nets D:\cad_nets.json -o out

:: 只看解析结果
python -m dfm info D:\gerber
```

## 5. 看懂结果

### 严重度分级

| 级别 | 含义 | 处置 |
| --- | --- | --- |
| 危险 | 超出板厂制程能力，**大概率做不出来或报废** | 必须改 |
| 高 | 接近制程极限 / 影响可靠性 | 建议改，或换更高能力等级、换板厂 |
| 中 | 影响成本或良率（含多数装配项） | 评估后决定 |
| 低 | 优化建议 | 可选 |
| 关闭 | 曾违规已关闭 | 记录用 |

### 可制造性评分

```
score = 100 − min(100, Σ(级别权重 × 该级别问题数))
默认权重: 危险 10 / 高 5 / 中 2 / 低 0.5
```

- ≥85 绿（可投产）、60–85 黄（评估后投产）、<60 红（不建议直接投产）
- 权重与基准分可在 `rules/checks.yaml` 的 `scoring` 段调整
- 同时给出「预估良率区间」（评分 ±2%），仅作管理参考

### 问题清单字段

对应 Valor DFM 报告：问题序号 / 规则名称 / 涉及层 / 从…开始 / 到…结束 / 测量值 / 规则值 / X / Y / 严重度 / 状态 / 问题描述 / 专家建议。

同一规则的多处违规会**汇总为一行**，`数量` 列给出总处数，`locations` 保留全部定位点（版图与 HTML 报告里可逐个跳转）。
