# 08 更新日志

## v1.1 — 判定正确性与解析完整性重构

本次更新针对代码审查发现的 **13 项 P0 缺陷**（会导致误判/漏判/结论不可信）逐条修复，
并新增几何内核 `dfm/geom`。所有修复均配套回归测试（测试数 131 → 214）。

### 一、几何内核（新增 `dfm/geom`）

| 缺陷 | 修复 |
| --- | --- |
| 焊盘按**外接圆**近似（矩形/椭圆/异形焊盘取 `max(w,h)/2`），长条焊盘系统性误报间距与阻焊桥违规 | 新增 `shapes.py`：圆/矩形(含旋转)/椭圆/多边形/圆弧真实形状；`clearance.py` 用 GEOS 精确净距，圆头图元走解析快路径（性能不降） |
| 铺铜只按**轮廓线**参与判定，面到面距离失真 | 铺铜以真实多边形（含内孔 `holes`）参与净距与连通性；仅有包围盒时标记 `approx`，参与连通但**不据此报短路** |
| **负片极性被忽略**：`clear` 字段解析后无人读取，内层平面/anti-pad/散热环被当成铜箔 → 假短路、假间距违规 | 新增 `polarity.py`：同层 `dark − clear` 逐元素布尔裁剪，保留网络/位号归属；被完全挖除的元素丢弃、部分挖除标记 `clipped`，统计写入数据质量 |
| 制造 DFM 与开短路**各自建一份元素表**（两份 40 万元素上限），重复计算 | 新增 `board.py`：`BoardGeometry` 一次构建，`ctx.geometry` 缓存后多检查复用 |
| 器件间距/基准点计数在 `core/source.py` 与 `checks/assembly.py` **各写一套算法**，Info 页数值与问题清单结论互相矛盾 | 新增 `measure.py` 单一实现（器件本体包围盒、最小间距、到板边、基准点、引脚间距），两侧共用；基准点关键字统一取规则集 `assembly.fiducial_names` |

### 二、解析层

| 缺陷 | 修复 |
| --- | --- |
| Gerber **光圈宏 `%AM` 直接跳过**，异形焊盘/金手指/Mark 尺寸读不出 | 新增 `io/aperture.py`：宏图元 1/2/20/21/22/4/5 完整展开，`$1..$9` 参数与 `+ - x / ( )` 表达式（自带安全求值器，不用 `eval`），`exposure=0` 做挖除；解析期扁平化为多边形点集 |
| Gerber **阵列光圈 SR / 区域阵列 `%SR`** 未展开 | `ADD..X<nx>Y<ny>I<dx>J<dy>` 与 `%SRX..Y..I..J..` 均展开为实例并计数 |
| Gerber **坐标未按 `%FS` 位宽换算**（`%FSLAX34Y34` 被误判为无法解析），导致坐标整体错一个数量级 | 修正 `%FS<L\|T><A\|I>X<int><dec>Y<int><dec>` 解析；支持前导零省略(L)与**尾随零省略(T)**；支持显式小数点写法 |
| Gerber `%AS` 轴选择、`%SF` 缩放、`%IP`/`%TF.FilePolarity` 负片、`%LN`、`G74/G75` 象限模式未处理 | 全部支持；单象限(G74)按"起止点等距"推断 I/J 符号；负片层给出明确提示 |
| Gerber 矩形/椭圆/多边形光圈只取 `min(w,h)`，忽略旋转与中心孔 | 保留 `shape/w/h/rot/hole/points`；中心孔 ≥ 光圈尺寸时忽略并提示 |
| Excellon **槽孔漏解析**（`G85` 与 `M15/M16` 铣槽），孔到线/孔到板边/孔环检查漏判 | 新增 `io/excellon.py`：`G85` 直线槽 + `M15/M16` 铣槽路径 → `is_slot/x2/y2/length_mm` |
| Excellon **重复孔 `R##`**、刀具表 `T01C0.3F200H500`、`T00` 卸刀、`G90/G91`、`METRIC/INCH,LZ/TZ`、`;FILE_FORMAT=i:d` 未处理 | 全部支持；绝对模式按次数展开、增量模式按偏移步进；刀具命中数统计；未定义刀具给出提示 |
| Excellon **英寸坐标未换算**（`X001000` 得 0.1 而非 2.54mm） | 整数坐标分支补 `× scale` |
| ODB++ **符号表解析后丢弃**，feature 无线宽/焊盘尺寸 → 下游回退 `or 0.3`，线宽/孔环/阻焊桥全部失真 | 新增 `io/odbpp.py`：符号表 `r/s/e/o/d/t/p/donut` → 真实形状与尺寸，写入 `shape/w/h/rot/width` |
| ODB++ **铺铜 `S`+`OB/OE`（含 `OS` 内孔）** 完全丢失；**阵列 `R`** 未展开 | surface 解析为带内孔的多边形；`R` 按 ODB++ 语义复制前序 feature 块并计数 |
| ODB++ **`features.z`(gzip) 与 `job.tgz/tar/zip` 压缩包无法读取**（真实作业几乎都是压缩包） | 支持 gzip 读取与 zip/tar/tgz 自动解包到临时目录后解析 |
| ODB++ matrix 解析（`STEP{}`/`LAYER{}` 块、`POLARITY=NEGATIVE`、层类型/顺序）不正确 | 正确解析块结构；层类型映射 `SIGNAL/POWER_GROUND/SOLDER_MASK/SILK_SCREEN/PASTE_MASK/DRILL/ROUT`；负片层与记录级极性做"负负得正"合成 |
| ODB++ 引脚号属性名读取错误（用 `.pin`，实际为 **`.pn`**）→ 网表全丢 | 同时兼容 `.pn`/`.pin`、`.comp`/`.cmp`；网表解析兼容 `+node` 续行、`;` 与 `,` 分隔 |
| ODB++ `components` 文件（器件位号/封装/坐标/面）未读取 | 解析并写入设计模型，供装配检查使用 |

### 三、结论可信度

| 缺陷 | 修复 |
| --- | --- |
| **实例截断污染"数量"**：每规则上限 500/300 条，`aggregate_by_rule` 用 `len(实例)` 当处数 → 密集板报"共 500 处"而真实数千处，且无截断标记 | 新增 `IssueCollector` 与装配 `_Sink`：**处数全量计数、实例按上限留存**；报告/界面显示真实处数，截断时标注 `truncated`/`instance_cap` 并在数据质量中列出 |
| **"接近极限"告警系数两套且全局配置失效**：检查层硬编码 `cap*1.2`/`cap*0.8`；规则集用 `min*max(ratio,1.0)`，而 `limit_warn_ratio=0.8` → 告警带恒为空 | 新增 `issue.warn_threshold()` / `classify_limit()` **唯一实现**；几何检查、能力比对、规则集改判全部走它；`limit_warn_ratio` 语义统一为"带宽系数"（0.8 → 上限的 1.25 倍内告警） |
| **能力库缺项静默跳过**：几何/装配检查在能力缺项时直接不判且无提示，用户误以为"通过" | 新增 `core/coverage.py`：每个检查记录 `judged/missed`，汇总为 `coverage_ratio` 与 `missed_rules`；生成「低」级提示问题（规则名 `部分规则未判定`）；界面结果页顶部横幅告警、Excel 新增**数据质量**页、HTML 新增数据质量区块、CLI 打印覆盖率 |
| **异常全吞**：解析/检查失败只进日志一行，分析仍报"成功" | 数据源解析失败且无任何可用数据 → **抛 `RuntimeError`**（CLI 返回码 1、界面弹错）；检查失败记入 `data_quality["致命问题"]` 并在报告与界面显式提示 |
| 解析受限信息（宏未展开、负片层、阵列展开、未定义刀具/符号、TZ 零省略）无处可查 | 各解析器输出 `notes`，汇入 `data_quality["解析提示"]`，进入报告与界面 |
| 潜在损失金额 `LOSS_BY_SEV` 硬编码在报告代码里，无出处且不可配 | 移到规则集 `cost` 段，**默认关闭**；启用时可自定义各级别金额与币种 |

### 五、验证阶段追加修复（写测试时新发现）

| 缺陷 | 修复 |
| --- | --- |
| ODB++ `components` 文件**按固定列号取值**，实际存在 `CMP <id> <refdes> <pkg> <x> <y> <rot> <side>` / `TOP <refdes> ...` 等多种写法 → 器件数恒为 0，装配检查拿不到器件 | 改为**定位首个连续数值对**作为 (x,y)，其前两字段为封装/位号；兼容三种写法、缺省 rotation、面别从尾部关键字识别 |
| ODB++ 层 bbox 只按坐标点计算，未含符号尺寸 → 只有焊盘/横向走线的层得到 H=0 的退化包围盒，被误报「坐标偏移」 | 新增 `_grow_bbox()`，按半个符号尺寸外扩 |
| 完整性检查对**阻焊/丝印/外形层**也要求网络属性 → 每份数据都误报「网络属性缺失」 | 新增 `_is_copper_layer()`（按 ODB `TYPE` / Gerber `TF.FileFunction` / 层名判定），只对铜层要求网络属性 |
| 「坐标偏移」把 H=0（只有横向走线的正常层）判为异常 | 仅在 W/H 为负或同时为 0（真正退化）时告警 |
| 「层间坐标偏移」拿阻焊层与铜层比原点 → 层类型不同、范围本就不同，必然误报 | 只在**同类层（铜层之间）**比较原点 |
| 文本报告缺数据质量段（Excel/HTML/CLI 都有），且标题残留旧品牌名 `Asher_DFM` | 补齐数据质量段（覆盖率/未判定规则/截断/致命/解析提示）与截断处数标注；标题改用 `dfm.branding.APP_NAME` |
| `odbpp.parse_job` 在层循环内定义闭包 `grow()` 捕获循环变量 `bbox`（ruff B023，跨轮次污染风险） | 提为模块级 `_grow_bbox(bbox, x, y, half)` 显式传参 |
| `IssueCollector.truncated()` 调用 `self.count((cat, rule))` 传元组给双参方法 → `TypeError` | 改为直接查 `self.counts` |
| `excellon` 英寸坐标整数分支漏乘 `scale` → `X001000` 得 0.1 而非 2.54mm | 整数分支补 `× scale()` |
| `odbpp` 引脚号读 `.pin`，ODB++ 实际属性名是 **`.pn`** → 网表全丢、`attributes_present` 恒为 False | 兼容 `.pn`/`.pin` 与 `.comp`/`.cmp` |
| `odbpp.parse_netlist` 只认 `+node` 续行，`NET;n1,n2` 写法节点丢失 | 兼容 `;` 与 `,` 分隔、行内节点与续行两种形式 |
| `Shape.arc_points` 用 `self.x2 or self.x` 回退 → **终点坐标为 0 时被当成缺失**，半径算错（实测 1.207 而非 1.0） | 全部改为显式 `is None` 判断 |
| `netlist._Node` 默认参数 `net=""` 使 `net if net is not None else el.net` 永远取空串 → **全部元素网络名为空**，短路判不出、开路全误报 | 默认值改为 `None`，回退到元素自身网络 |
| `gerber` 解析 `%FS` 的正则写成 `([LA])([IT])`，与规范 `([LT])([AI])` 相反 → 标准 `%FSLAX34Y34` **解析失败**，坐标退回原始整数（差 10⁴ 倍） | 修正为 `([LT])([AI])`，并支持缺省声明时的回退与提示 |
| `gerber._coord` 未按 `%FS` 位宽换算 | 实现隐含小数（LA/TZ 两种零省略）与显式小数点两种写法 |
