# 07 检查规则清单

判定阈值来源两类：

- **能力库**：`rules/capability/<板厂>.yaml`，随板厂/板型/能力等级/铜厚变化
- **规则集**：`rules/checks.yaml` 的 `assembly` / `panelization` 段（客户或 SMT 厂标准）

严重度通用规则：超出能力 → **危险**；接近极限（默认系数 0.8，见 `limit_warn_ratio`）→ **高**；
影响成本/良率 → **中**；优化建议 → **低**。所有规则均可在规则集中按名覆盖严重度、阈值或停用。

`定位` 列：✓ 表示带 XY 坐标，可在版图页交叉定位。

---

## 1. 几何制造 DFM（`fabrication`，检查 id `fabrication`）

数据源：几何模型（BRD/JSON/Gerber/ODB++）+ 能力库。逐处判定，同类汇总为一行并保留全部定位点。

| 类别 | 规则 | 判定 | 能力库来源 | 默认严重度 | 定位 |
| --- | --- | --- | --- | --- | --- |
| 线路 | 最小线宽 | 走线实测线宽 < 能力（按成品铜厚分档） | `trace.min_line_spacing_by_copper` | 危险 / 高(接近) | ✓ |
| 线路 | 最小线距 | 不同网络同层铜箔净距 < 能力 | `trace.min_line_spacing_by_copper` | 危险 / 高 | ✓ |
| 线路 | 外层线路到板边 | 外层铜箔到成型线 < 要求 | `trace.trace_to_board_edge.outer` | 高 | ✓ |
| 线路 | 内层线路到板边 | 内层铜箔到成型线 < 要求 | `trace.trace_to_board_edge.inner` | 高 | ✓ |
| 钻孔 | 最小机械钻孔 | 机械孔径 < 能力 | `drill.min_mech_drill` | 危险 / 高 | ✓ |
| 钻孔 | 最大机械钻孔 | 孔径 > 能力 | `drill.max_mech_drill` | 中 | ✓ |
| 钻孔 | 最小激光孔 | 激光/盲孔孔径 < 能力 | `drill.min_laser_via` | 危险 / 高 | ✓ |
| 钻孔 | 单边孔环(机械孔) | (焊盘−孔径)/2 < 能力 | `drill.annular_ring_mech` | 危险 / 高 | ✓ |
| 钻孔 | 最小激光孔环 | 激光孔单边孔环 < 能力 | `drill.annular_ring_laser` | 危险 / 高 | ✓ |
| 钻孔 | PTH纵横比 | 板厚/孔径 > 能力 | `plating.pth_aspect_ratio` | 高 | ✓ |
| 阻焊 | 最小阻焊桥 | 外层焊盘/过孔间净距 < 能力（按铜厚 oz 分档） | `solder_mask.min_bridge_by_copper` / `min_bridge_single` | 危险 / 高 | ✓ |
| 测试 | 电测PAD(二线) | 测试点焊盘 < 能力 | `test.min_pad_2wire` | 危险 / 高 | ✓ |
| DRC | Allegro DRC 透传 | `.brd`/extracta 自带的 DRC 违规（含类型、层、文本） | — | 危险(error)/高 | ✓ |

说明：

- 走线宽为「网络平均值」时（`etch_width_is_average=True`），间距与短路判定只采信焊盘/过孔的真实尺寸，避免误报
- 板框缺失（Gerber 无轮廓层）时**跳过**到板边检查，避免把铜箔外包框当板边导致全板误判
- 每类规则最多保留 500 处实例（超出在描述中标注截断）

几何量测部分（`dfm/checks/assembly.py`）：

| 类别 | 规则 | 判定 | 阈值来源（规则集 `assembly`） | 默认严重度 | 定位 |
| --- | --- | --- | --- | --- | --- |
| 组装 | 器件间距 | 器件本体（焊盘包围盒近似）最小间距 < 要求 | `min_component_spacing` | 中 | ✓ |
| 组装 | 器件到板边 | 器件本体到成型线 < 要求 | `component_to_edge` / `component_to_edge_severity` | 中 | ✓ |
| 组装 | 焊盘到板边 | SMD 焊盘边缘到成型线 < 要求 | `pad_to_edge` | 中 | ✓ |

| 组装 | BGA焊盘 | 器件引脚间距 < 要求；或细间距器件单边孔环 < 要求 | `bga_pitch_min` / `bga_pad_annular` | 中 / 高 | ✓ |
| 组装 | Via in Pad | 过孔落在 SMD 焊盘内（锡膏流失→虚焊/空洞） | `via_in_pad_allowed` | 高（允许时低） | ✓ |
| 丝印 | 丝印上焊盘 | 丝印图形与 SMD 焊盘重叠（需 Gerber 丝印层） | — | 中 | ✓ |
| 组装 | 基准点数量 | 未识别到基准点，或某面数量 < 要求 | `fiducial_min` / `fiducial_names` | 高 | ✓(有坐标时) |
| 组装 | 基准点尺寸 | 基准点焊盘直径 < 要求 | `fiducial_diameter` | 中 | ✓ |
| 测试 | 测试点覆盖率 | 有测试点的网络占比 < 要求 | `test_coverage_min` | 中 | — |
| 测试 | 测试点尺寸 | 测试点焊盘直径 < 要求 | `test_pad_diameter` | 中 | ✓ |
| 测试 | 测试点到板边 | 测试点到成型线 < 要求（治具/轨道干涉） | `test_pad_to_edge` | 中 | ✓ |

参数化部分（`dfm/core/issue.py`，来自设计参数或人工填写）：

| 类别 | 规则 | 判定 | 默认严重度 |
| --- | --- | --- | --- |
| 组装 | 器件间距 | `min_component_spacing` 参数 < 建议值 | 中 |
| 组装 | 基准点数量 | `fiducial_count_top/bottom` < 要求 | 高 |
| 组装 | 器件到板边 | `component_to_edge` < 建议值 | 中 |
| 组装 | 测试点尺寸 | `test_pad_diameter` < 建议值 | 中 |
| 组装 | 测试点到板边 | `test_pad_to_edge` < 建议值 | 中 |
| 组装 | 片式元件焊盘对称性 | `chip_pad_symmetry_ratio` < 建议值 | 中 |
| 组装 | 极性标识 | `polarity_marked` 为假（反向贴装风险） | 高 |
| 组装 | BGA焊盘 | `bga_pitch` / `bga_pad_annular` < 建议值 | 中 / 高 |

## 3. 开短路 + 网表一致性（`netlist`）

| 类别 | 规则 | 判定 | 默认严重度 | 定位 |
| --- | --- | --- | --- | --- |
| 开短路 | 开路(Open) | 逻辑网络的焊盘/过孔/走线被分割成多个连通域；或逻辑节点无对应铜箔 | 危险 | ✓ |
| 开短路 | 短路(Short) | 不同网络铜箔在同层实际接触/重叠（用真实走线、焊盘、过孔几何；铺铜只参与开路连通） | 危险 | ✓ |
| 网表 | 网表一致性 | 逻辑网络数 vs 物理连通域数、开路网络数、短路网络对数、无铜节点数汇总 | 低(通过)/危险 | — |

补充：若 `.brd` 由 extracta 提取，Allegro 自身连通性（`opens`）作为权威开路数据参与判定。
数据量大时按元素上限（40 万）截断并在摘要中标注。

## 4. CAD vs FAB 网络比对（`fabnet`）

| 类别 | 规则 | 判定 | 默认严重度 |
| --- | --- | --- | --- |
| 网络比对 | 开路(Open) | CAD 有该网络连接，制造数据中缺失 | 危险 |
| 网络比对 | 短路(Short) | 制造数据出现 CAD 中没有的连接 | 危险 |
| 网络比对 | 网络缺失 | CAD 网络在制造数据中完全不存在 | 高 |
| 网络比对 | 多余网络 | 制造数据出现 CAD 中不存在的网络 | 高 |
| 网络比对 | 网络一致性 | 比对通过时的信息项 | 低 |

制造数据侧网表来源优先级：Gerber X2 属性（`%TO.N`/`%TO.P`）或 ODB++ netlist → 设计模型节点汇总。

## 5. 制程能力比对（`capability`，参数化）

逐项输出 `PASS / WARN(接近极限) / FAIL / INFO(无能力数据，需与板厂评估)`，FAIL 与 WARN 转为问题。

| 类别 | 规则 | 能力库来源 |
| --- | --- | --- |
| 拼板 | 板尺寸 | `panel.max_working_panel` |
| 压合 | 板厚范围 | `lamination.board_thickness.min_mm/max_mm` |
| 线路 | 最小线宽 / 最小线距 | `trace.min_line_spacing_by_copper`（按铜厚分档） |
| 线路 | 不同网络孔壁间距 | `trace.hole_to_hole_spacing.pth_to_pth`（CAF 风险） |
| 线路 | 内层/外层线路到板边 | `trace.trace_to_board_edge` |
| 钻孔 | 最小/最大机械钻孔 | `drill.min_mech_drill` / `max_mech_drill` |
| 钻孔 | 最小激光孔 | `drill.min_laser_via` |
| 钻孔 | 单边孔环(机械孔) / 最小激光孔环 | `drill.annular_ring_mech` / `annular_ring_laser` |
| 钻孔 | PTH纵横比 | `plating.pth_aspect_ratio`（能力值 <2 视为存疑，只提示不判定） |
| 钻孔 | NPTH孔到板边 | `drill.npth_to_edge`（破孔风险） |
| 钻孔 | 盲孔填孔纵横比 | `plating.blind_via_fill_aspect` |
| 钻孔 | 激光孔介质厚度 | `drill.laser_dielectric_limit`（按孔径分档） |
| 阻焊 | 最小阻焊桥 | `solder_mask.min_bridge_by_copper` / `min_bridge_single` |
| 阻焊 | 阻焊开窗最小尺寸 | `solder_mask.min_opening` |
| 阻焊 | 阻焊油墨厚度 | `solder_mask.ink_thickness_by_copper`（上下限） |
| 丝印 | 最小文字线宽 / 最小文字间隙 | `silkscreen.min_line_width` / `min_clearance` |
| 丝印 | 最小字符尺寸 | `silkscreen.min_char_size`（mil → mm） |
| 丝印 | 丝印到阻焊 / 丝印离成型线 | `silkscreen.min_to_solder_mask` / `min_to_outline` |
| 塞孔 | 树脂塞孔条件 | `plug_hole.resin_plug_min`（孔径 + 板厚） |
| 塞孔 | 树脂塞孔深度 / 油墨塞孔深度 | `plug_hole.resin_plug_depth` / `ink_plug_depth` |
| 塞孔 | 塞孔纵横比 | `plug_hole.plug_aspect_ratio`（板厚/塞孔孔径） |
| 覆盖膜(软板) | 覆盖膜开窗最小间距 / 开窗到焊盘 / 开窗到线路 / 覆盖膜最小开窗 | `coverlay.*` |
| 测试 | 电测PAD(二线) / 电测PAD(四线-宽) | `test.min_pad_2wire` / `min_pad_4wire` |
| 表面处理 | 表面处理 | `surface_finish` 支持的工艺键 |

Info 页还会给出：线宽公差（按线宽分档）、层间对位、孔壁粗糙度、AOI 最小检测。

> 几何检查已判定并定位的规则（如最小线宽），参数化比对不再重复报告。

## 6. 拼板 / 工艺边（`panelization`，参数化）

| 类别 | 规则 | 判定 | 阈值来源 | 默认严重度 |
| --- | --- | --- | --- | --- |
| 拼板 | 拼板方式 | `panelized` 为假；若板尺寸小且器件到板边 <5mm，提示传送撞件 | — | 高 |
| 拼板 | 工艺边 | `process_edge_mm` < 要求 | `panelization.process_edge` | 中 |
| 拼板 | Mark点数量 | `mark_count` < 要求 | `panelization.mark_count` | 高 |
| 拼板 | Mark点数量（到工艺边） | `mark_to_edge_mm` < 要求 | `panelization.mark_to_edge` | 中 |
| 拼板 | 定位孔 | `tooling_hole_count` < 建议 | `panelization.tooling_hole_count` | 中 |
| 拼板 | 板材利用率 | `panel_utilization` < 建议（成本） | `panelization.min_utilization` | 低 |
| 拼板 | 板尺寸 | 拼板尺寸超出最大工作板 | `panel.max_working_panel` | 危险 |

> 本版**不含**拼板排版设计器，只做 DFM 判定。

## 7. 制造数据完整性（`fabdata`）

| 类别 | 规则 | 判定 | 默认严重度 |
| --- | --- | --- | --- |
| 制造数据 | 数据缺失 | 未解析到任何 Gerber/ODB++/钻孔数据 | 危险 |
| 制造数据 | 图形层缺失 | 无铜层 / 无阻焊 / 无丝印 / 无外形层 | 高 / 中 |
| 制造数据 | 钻孔层缺失 | 有铜层但无钻孔文件 | 高 |
| 制造数据 | 钻孔为空 | 钻孔文件内无孔 | 高 |
| 制造数据 | 空图层 | 图层无任何图形 | 中 |
| 制造数据 | 图层重复 | 同一功能层出现多个文件 | 中 |
| 制造数据 | 孔径未定义 | 钻孔工具号无孔径定义 | 高 |
| 制造数据 | 孔径定义错误 | 孔径 ≤0 或异常大 | 高 |
| 制造数据 | 镀通孔标注 | 钻孔文件未标注 PTH/NPTH | 低 |
| 制造数据 | 网络属性缺失 | Gerber 无 X2 网络属性（无法做网表比对） | 中 |
| 制造数据 | 坐标偏移 | 图层坐标超出常规范围/负坐标异常 | 中 |
| 制造数据 | 层间坐标偏移 | 各层原点偏移 >1mm（对位风险） | 高 |

## 8. 网络分类 / 阻抗需求（`netclass`）

| 类别 | 规则 | 判定 | 默认严重度 |
| --- | --- | --- | --- |
| 网表 | 阻抗需求未声明 | 识别到高速/差分网络，但设计参数未声明阻抗要求 | 高 |
| 网表 | 差分对不成对 | 差分类网络命名有极性后缀但配不上对 | 中 |

识别的类别（按网络名模式，可在规则集 `netclass.patterns` 扩展）：
`POWER` `GND` `CLOCK` `DDR`(100Ω) `PCIE`(85Ω) `USB3`(90Ω) `USB2`(90Ω) `MIPI`(100Ω)
`LVDS`(100Ω) `ETHERNET`(100Ω) `CAN`(120Ω) `RF`(50Ω) `SPI` `I2C` `UART` `JTAG`
`SENSE` `GATE_DRIVE` `LED` `DEFAULT`。

差分对命名支持：`_P/_N`、`_H/_L`、`_POS/_NEG`、`_PLUS/_MINUS`、`DP/DM`、无下划线的 `P/N`、`H/L`。

统计结果（网络总数、各类数量、差分对数、阻抗网络数与目标阻抗）写入报告 Info 页与 `analysis["net_classes"]`。

## 9. 自定义规则（`custom_rules`）

由 `rules/checks.yaml` 的 `custom_rules` 声明，问题代码用你指定的 `id`（不被统一重编覆盖），
类别默认「自定义」。运算符与可用参数见 [03 规则库配置指南](03-规则库配置指南.md#36-声明式自定义规则)。

## 10. 插件检查

`plugins/` 目录中注册的检查同样出现在本清单的运行结果里，来源列显示插件文件名。
示例插件（`plugins/_sample_check.py`，默认不加载）提供：铜层数与压合风险、板长宽比与传送、上下层铜箔平衡。

```bat

```
