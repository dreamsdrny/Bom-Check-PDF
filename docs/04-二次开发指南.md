# 04 二次开发指南

Evan DFM 的三个扩展点，按成本从低到高：

| 需求 | 方式 | 是否写代码 |
| --- | --- | --- |
| 改判定阈值 / 加严放宽 / 停用它 | `rules/checks.yaml` | 否 |
| 换板厂 / 加能力等级 / 加板型 | `rules/capability/*.yaml` | 否 |
| 新增参数级判定（板厚、表面处理、层数…） | `checks.yaml` 的 `custom_rules` | 否 |
| 新增**几何级**检查（需要读走线/焊盘/过孔坐标） | 插件（一个 `.py`） | 是，约 20 行 |
| 新增界面页 / 改报告格式 / 集成 MES | Python API | 是 |

分层原则：**geom/core/checks/io/report 不依赖 Qt**，可单独在 CI、服务端、脚本中调用；
只有 `ui/` 依赖 PySide6。二次开发做自动化时只需 `from dfm import analyze_file`。

## 2. 核心数据结构

### 2.1 Issue（问题）

`dfm.core.issue.make_issue()` 生成，全系统统一：

```python
{
  "code": "FAB-TR-01",      # 问题代码 (renumber_issues 统一重编; keep_code=True 可保留)
  "category": "线路",        # 类别: 线路/钻孔/阻焊/丝印/塞孔/覆盖膜/测试/压合/板厚/
                            #       表面处理/锣型/补强/拼板/组装/网表/DRC/制造数据/自定义
  "rule": "最小线宽",        # 规则名 (规则集按此名覆盖阈值/严重度)
  "severity": "危险",        # 危险/高/中/低/关闭
  "status": "打开",
  "description": "...",      # 问题描述
  "suggestion": "...",       # 专家建议
  "measured": 0.05,          # 实测值
  "required": 0.07,          # 要求值
  "unit": "mm",
  "layer": "TOP", "net": "SIG1",
  "from": "SIG1", "to": "GND",   # 涉及对象 (如间距的两个网络)
  "x": 30.0, "y": 11.0,      # 定位坐标 (mm); None 表示无定位
  "count": 1,                # 汇总后的处数
  "note": "铜厚 35um",
  # 汇总/编排阶段附加:
  "module": "fabrication",   # 产出该问题的检查 id
  "check_name": "几何制造 DFM",
  "locations": [[x, y], ...] # aggregate_by_rule 后保留的全部定位点
}
```

## 3. 写一个检查插件（最常见需求）

### 3.1 最小示例

`plugins/my_checks.py`：

```python
from dfm.core.issue import make_issue
from dfm.core.registry import REQ_DESIGN, register_check


@register_check(
    id="my_copper_balance",          # 唯一 id (界面/配置/命令行都用它)
    name="铜箔分布平衡度",             # 界面显示名
    group="制造 DFM",                 # 分组: 制造 DFM / 装配 DFM / 网表 / 拼板 / 制造数据
    description="上下外层铜量差异过大时提示翘曲风险",
    requires=(REQ_DESIGN,),           # 依赖数据, 不满足自动跳过
    order=90,                         # 执行顺序 (小者先)
)
def run(ctx):
    layers = ctx.design.copper_layers()
    if len(layers) < 2:
        return []
    top, bot = layers[0], layers[-1]
    n_top = sum(1 for c in ctx.design.clines if c["layer"] == top)
    n_bot = sum(1 for c in ctx.design.clines if c["layer"] == bot)
    diff = abs(n_top - n_bot) / max(n_top, n_bot, 1)
    limit = float(ctx.rule_param("my_rules", "max_imbalance", 0.6))   # 读规则集阈值
    if diff <= limit:
        return []
    return [make_issue(
        code="MY-01", category="压合", rule="铜箔分布不平衡", severity="中",
        description=f"{top} {n_top} 段 / {bot} {n_bot} 段, 不平衡度 {diff:.0%}",
        measured=round(diff, 3), required=limit, unit="ratio",
        suggestion="稀疏面加铺铜/网格铜平衡铜量")]
```

放进 `plugins/`（或 `%APPDATA%\EvanDFM\plugins\`），界面「规则库 → 插件与检查项」点 **重新加载插件**，或重启软件。
命令行验证：

```bat
python -m dfm checks                 # 应出现 my_copper_balance, 来源=文件名
python -m dfm analyze board.json --modules my_copper_balance
```

### 3.2 CheckContext 全部能力

```python
ctx.design          BrdDesign (无几何时为 None)
ctx.params          设计参数 dict (自动量测 + 人工)
ctx.capability      当前板厂能力库 dict (已按板型/等级选定)
ctx.fab_data        渲染几何
ctx.fab_stats       制造数据统计 {gerber_layers, drill_files, feature_count, hole_count, ...}
ctx.cad_nets        CAD 网表 {net: {refdes.pin}}
ctx.fab_nets        制造数据侧网表
ctx.rules           RulesConfig
ctx.options         {factory, board_type, capability_level, copper_um, copper_oz,
                     board_thickness, element_cap, instance_cap}
ctx.extras          dict: 写入的内容会合并进 analysis / 报告 Info 页
ctx.geometry        ★ 共享 BoardGeometry (真实形状 + 极性合成 + 索引, 惰性构建并缓存)
ctx.coverage        已登记的 Coverage 列表
ctx.truncations     已登记的截断说明
ctx.factory / ctx.board_type / ctx.level / ctx.copper_um / ctx.copper_oz / ctx.board_thickness
ctx.param(key, default)                  读设计参数
ctx.rule_param(group, key, default)      读规则集参数组 (checks.yaml)
ctx.note("消息")                          输出到进度/日志
ctx.issue(**make_issue_kwargs)           构造并入队一个 Issue
ctx.add(issue) / ctx.add_many(issues)
ctx.set_geometry(geom)                   注入自定义几何模型 (一般不需要)
ctx.set_coverage(cov)                    登记判定覆盖率 → 报告「数据质量」
ctx.add_truncation("说明")                登记截断信息 → 报告「数据质量」
ctx.available()                          当前具备的数据集合
```

`requires` 可选值：`design` `fab` `params` `cad` `capability`（`dfm.core.registry` 中的 `REQ_*` 常量）。

### 3.3 返回「实例」还是「问题」

- 返回**每处一条**的实例（带 `x`/`y`）时，用 `aggregate_by_rule()` 汇总，界面才会显示"共 N 处"并支持逐点定位：

```python
from dfm.core.issue import aggregate_by_rule

def run(ctx):
    instances = []
    for v in ctx.design.vias:
        if v["drill_mm"] and v["drill_mm"] < 0.15:
            instances.append(make_issue(code="X", category="钻孔", rule="超小孔径",
                                        severity="危险", description="...",
                                        x=v["x"], y=v["y"], measured=v["drill_mm"],
                                        required=0.15, unit="mm"))
    ctx.extras.setdefault("instances", []).extend(instances)   # 供版图渲染标记
    return aggregate_by_rule(instances)
```

- 返回**整体一条**的结论（如覆盖率、平衡度）时直接返回 Issue 列表即可。

### 3.4 用共享几何模型写高精度检查（推荐）

`ctx.geometry` 是**一次构建、多检查复用**的 `BoardGeometry`：已完成真实形状构造与
负片极性合成，直接用它做判定，既准确又不用重复建表。

```python
from dfm.core.coverage import Coverage
from dfm.core.issue import IssueCollector, classify_limit
from dfm.core.registry import REQ_CAPABILITY, REQ_DESIGN, register_check
from dfm.geom.clearance import element_clearance
from dfm.geom.elements import ELEMENT_PAD, ELEMENT_TRACE


@register_check(id="my_spacing", name="我的间距检查", group="制造 DFM",
                requires=(REQ_DESIGN, REQ_CAPABILITY), order=95)
def run(ctx):
    geom = ctx.geometry                      # 共享模型 (勿自行 new BoardGeometry)
    cap = 0.15                               # 实际应取自 ctx.capability / 规则集
    col = IssueCollector(cap=500)            # 处数全量计数, 实例按上限留存
    cov = Coverage(check_id="my_spacing")
    cov.judged("线路", "我的间距", cap)

    els = geom.elements
    for i, j in geom.candidates(cap):        # 包围盒广相 (已按容差剪枝)
        a, b = els[i], els[j]
        if a.layer != b.layer or a.net == b.net:
            continue
        dist, x, y = element_clearance(a, b) # 真实形状净距 (圆头走解析快路径)
        sev = classify_limit(dist, cap, higher_is_better=True,
                             ratio=ctx.rules.limit_warn_ratio() if ctx.rules else None)
        if sev:
            col.add("线路", "我的间距", sev,
                    f"{a.label()} 与 {b.label()} 净距 {dist:.4f}mm < {cap}mm",
                    x=x, y=y, layer=a.layer, net=a.net,
                    measured=round(dist, 4), required=cap, unit="mm",
                    from_=a.label(), to=b.label(), suggestion="增大间距")
    ctx.set_coverage(cov)                    # 覆盖率进入报告「数据质量」
    for r in col.truncated_rules():
        ctx.add_truncation(f"{r} 处数超出留存上限, 已按真实计数报告")
    ctx.extras.setdefault("instances", []).extend(col.instances)   # 供版图交叉定位
    return col.aggregate()
```

要点：

* `Element` 字段：`kind`(trace/pad/via/pour/hole)、`shape`(真实形状)、`layer`、`net`、
  `ref`/`pin`、`polarity`、`minx/miny/maxx/maxy`、`attrs`、`clipped`(被负片裁剪过)、
  `geometry`(极性合成后的有效 shapely 几何)
* `geom.copper(layer=None)` / `geom.holes` / `geom.layers()` / `geom.outer_layers()` /
  `geom.bbox()` / `geom.summary()`
* **不要**自己 `new BoardGeometry`：会重复建表（数十万元素），用 `ctx.geometry`
* 处数一律走 `IssueCollector`（`col.total()` / `col.count(cat, rule)` /
  `col.truncated_rules()`），不要把 `len(instances)` 当处数
* 告警带一律走 `dfm.core.issue.classify_limit` / `warn_threshold`，不要硬编码 1.2/0.8
* 能力库缺项要 `cov.missed(...)` 显式记录，不要静默跳过

### 3.5 性能建议

- 元素配对用 `geom.candidates(tol)`（包围盒扫描剪枝）；自定义集合用
  `dfm.geom.clearance.pair_candidates` 或 `dfm.io.brd_model.SpatialGrid`，不要写双重循环
- 圆头图元（圆焊盘/圆头走线）走解析快路径，只有矩形/椭圆/多边形/被裁剪元素才调 GEOS
- 给自己设实例上限（内置检查用 500/300），超出后由 `IssueCollector` 标记截断
- 昂贵统计写入 `ctx.extras`，避免重复计算
- 插件里不要 `import` Qt；几何/报告逻辑保持与 UI 解耦

### 3.6 插件的其他形态

```python
# 包形式: plugins/my_pkg/__init__.py
def register():          # 可选: 加载后自动调用
    ...
```

`_` 或 `.` 开头的文件/目录会被跳过（用于随包分发的示例）。
加载失败不会影响主流程，错误会显示在「规则库 → 插件」日志与 `analysis["plugins"]` 中。

## 9. 打包

```bat
build.bat              :: PyInstaller, 产物 dist\EvanDFM.exe
build.bat clean        :: 清理
build.bat run          :: 打包后运行
```

`EvanDFM.spec` 要点：

- `datas` 打入 `rules/`、`assets/`、`plugins/`
- `hiddenimports` 显式列出所有检查模块（注册靠 import 副作用，打包器无法静态推断）
- `excludes` 去掉 tkinter/matplotlib/scipy/pandas 与未用的 Qt 模块，显著减小体积
- `console=False`（需要看命令行输出时改 `True`，或用 `python -m dfm`）
- `manifest=Evan_DFM.manifest`：Per-Monitor V2 高 DPI + UTF-8 代码页 + 长路径

打包后路径解析：`dfm/paths.py` 中 `app_root()` 为 exe 所在目录、`bundle_dir()` 为解包目录，
两者下的 `rules/`、`plugins/` 都会被搜索；用户自定义仍优先走 `%APPDATA%\EvanDFM\`。

**新增检查模块或插件后，记得把模块名加进 `EvanDFM.spec` 的 `hiddenimports`。**

## 10. 编码约定

- 全量 UTF-8；注释与文档字符串用中文，标识符用英文
- 长度单位统一 **mm**（解析层负责 um/mil/inch 换算），坐标 Y 向上
- 检查函数**不抛异常**：可预期的数据缺失用 `return []` + `ctx.note()` 说明
- 所有阈值走能力库或规则集，**不要在代码里写死数值**
- core/checks/io/report **不得 import Qt**
- 新增文件要有模块级文档字符串，说明职责、输入输出与单位约定
